# RE:WEAR 웹 시제품

`index.html`을 브라우저로 열면 작동하는 단일 페이지 시제품입니다. 별도 설치가 필요 없습니다.

## 포함한 사용자 흐름

1. 새 옷의 기준 사진과 현재 사진 촬영/업로드
2. 2D 빠른 촬영 또는 3D 정밀 촬영 선택
3. 분석 결과에 따른 중고 거래 권장(손상·변형도 60% 이하) 또는 원단 순환 권장(60% 초과)
4. 거래·판매 포인트 및 향후 결제수단 연동 안내

## 실제 측정 시스템 권장 설계

### 결론

위상식 무아레(실무적으로는 **위상식 프린지 투영 profilometry**)는 의류 표면의 3D 형상 변화—늘어짐, 주름, 국부적인 함몰·돌출—를 비교하는 데 사용할 수 있습니다. 그러나 보풀, 얼룩, 변색, 미세 마모처럼 깊이 변화가 거의 없는 손상은 단독으로 신뢰성 있게 측정하기 어렵습니다. 따라서 **3D 무아레 지표 + 2D 컴퓨터 비전 지표**를 함께 사용하는 것이 적절합니다.

### 권장 파이프라인

1. **캘리브레이션**: 고정된 카메라와 소형 DLP/휴대폰 화면 프로젝터의 내부·외부 파라미터를 체커보드로 보정합니다. 의류를 놓을 매트에도 기준 마커를 둡니다.
2. **기준 기록**: 옷을 동일한 매트에 평평하게 고정하고 정현파 격자를 0°, 90°, 180°, 270° 위상으로 순차 투영·촬영합니다. 여러 주파수를 쓰면 위상 언랩의 실패를 줄일 수 있습니다.
3. **현재 기록**: 동일한 조명·거리·고정 방식을 반복합니다. 3D 모드에서는 앞면, 좌 45°, 우 45°를 추가해 옷의 깊은 주름이나 가려진 부분을 보완합니다.
4. **복원**: 각 픽셀에서 4단계 위상값을 구하고, 언랩과 카메라-프로젝터 삼각측량으로 높이 맵을 복원합니다. 기준 마커와 의류 외곽선을 사용해 두 기록을 정합합니다.
5. **점수화**: 3D에서는 평균 절대 높이 차이, 주름 면적, 변형 영역 비율을 산출합니다. 2D에서는 색 차이(예: CIEDE2000), 텍스처/보풀, 얼룩 분할, 윤곽 변화로 외관 손상을 구합니다. 카테고리별 가중치를 둔 통합 점수로 60% 임계값을 적용합니다.

### 1장 촬영이 가능한 경우와 아닌 경우

- **2D 외관 판정**은 동일한 평면·조명·거리의 단일 사진 한 장씩으로 가능합니다. 이 웹의 ‘2D 빠른 촬영’이 해당합니다.
- **3D 절대 형상**은 일반 카메라 사진 한 장만으로는 안정적으로 계산할 수 없습니다. 카메라와 프로젝터가 보정돼 있고 단일 프린지에서 위상을 복원할 수 있는 특수 단일샷 방식은 가능하지만, 정확도·패턴 품질·가림에 민감합니다.
- 소비자 서비스의 초기 버전은 2D를 기본으로 하고, 높은 신뢰도가 필요한 옷에만 고정 거치대와 4단계 프린지·3각도 촬영을 제공하는 구성이 현실적입니다.

### 웹 구현 구성

- **브라우저**: `navigator.mediaDevices.getUserMedia()`로 카메라를 열고, Canvas/WebGL로 정현파 프린지(격자)를 전체 화면에 표시합니다. 촬영 중 자동 노출·화이트밸런스가 바뀌지 않도록 가능한 범위에서 제어합니다.
- **처리**: OpenCV.js 또는 WebAssembly 기반 OpenCV에서 체커보드/마커 검출, 의류 마스크, 특징점 정합을 수행합니다. 무거운 위상 언랩·3D 복원은 서버 GPU 작업으로 분리하는 편이 안정적입니다.
- **데이터**: 원본 사진, 촬영 환경, 보정 버전, 의류 마스크, 측정 신뢰도와 분석 결과를 함께 저장합니다. 신뢰도가 낮으면 재촬영을 요청하고 자동 거래 경로를 확정하지 않습니다.

## 주의 사항

- 광택·반투명·검은색 소재, 강한 무늬, 큰 주름, 이동은 프린지 대비를 낮춰 오차를 키울 수 있습니다. 확산 조명과 무광 배경, 옷 고정, 품질 검사 단계가 필요합니다.
- 의류의 ‘재판매 가능성’은 구조적 손상 외에도 위생·브랜드 정책·사용자 고지에 좌우됩니다. 60%는 제품 정책 임계값으로, 실제 거래 데이터를 통해 보정해야 합니다.
- 네이버페이·동백전 전환은 각각의 제휴·정산·전자금융 및 개인정보 요건을 검토한 뒤 구현해야 합니다. 이 시제품은 연동 준비 상태만 표현합니다.

## 참고 문헌

- Chao Zuo et al., “Phase shifting algorithms for fringe projection profilometry: A review,” *Optics and Lasers in Engineering* 109 (2018). 위상식 프린지 투영 방식과 오차 요인을 폭넓게 정리합니다.
- Hongjian Shi et al., “Shape and deformation measurement system by combining fringe projection and digital image correlation,” *Optics and Lasers in Engineering* 51(1) (2013). 프린지 투영으로 표면 형상/외곽 변형, 이미지 상관으로 평면 변형을 결합한 사례입니다.
- Huimin Zhao et al., “Modeling the measurement precision of Fringe Projection Profilometry,” *Sensors* 23(22) (2023). 카메라-프로젝터 대응점, 위상 측정, 정밀도 모델을 설명합니다.
